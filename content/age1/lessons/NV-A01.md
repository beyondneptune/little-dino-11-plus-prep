# Shape patterns
*Wiwaxia station · Age 1: Cambrian Seas*

## Learn
In a shape series, each picture changes by the **same rule** every step. Look for
what changes: the shape might **turn**, it might gain **one more dot**, the
**shading** might flip, or the shape might **grow a side**. Spot the rule, then
do it one more time to find the next picture.

## Remember
Find the rule that repeats, then apply it once more.
