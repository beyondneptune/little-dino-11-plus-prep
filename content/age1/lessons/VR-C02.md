# Letter sequences
*Pikaia station · Age 1: Cambrian Seas*

## Learn
In a letter sequence, find the **jump** from one letter to the next, then use the
same jump to find the missing letter. Count the steps in the alphabet, not the
letters. The jump can go **forwards** or **backwards**.

## Worked examples
1. **C, F, I, L, ?** From C to F is a jump of **+3** (C→D→E→F). The same +3 from L
   gives **O**.
   *Common mistake:* counting letters instead of the gaps between them.
2. **L, K, J, I, ?** This jumps **−1** each time (backwards). So after I comes **H**.
3. **T, V, X, Z, ?** This jumps **+2**, and after Z the alphabet wraps round to the
   start, so the next letter is **B**.

## Remember
Find the jump, then add it to the last letter (wrap Z→A if you need to).
