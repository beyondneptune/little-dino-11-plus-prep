# Comparing and ordering numbers
*Trilobite station · Age 1: Cambrian Seas*

## Learn
To compare whole numbers, first count the **digits**. The number with **more
digits is bigger**. If two numbers have the same number of digits, compare them
from the **left**. The first place where the digits are different decides it — a
bigger digit there means a bigger number.

## Worked examples
1. **Which is larger, 526 or 97?** 526 has three digits and 97 has two, so **526**
   is larger.
   *Common mistake:* thinking 97 is bigger because 9 is a big digit.
2. **Which is larger, 3471 or 3419?** They start the same: 3, 4. The next digit is
   **7** against **1**, so **3471** is larger.
3. **Which is smallest: 80, 108, 81?** 80 and 81 have two digits, 108 has three.
   The smallest is **80**, because 80 is less than 81.

## Remember
More digits means bigger. Same digits? Compare from the left.
